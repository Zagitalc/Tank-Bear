# Tank Bear 0.2.3-beta

Android friend beta — build 5. This is a prerelease for testing.

## Download and install

Download **Tank-Bear-0.2.3-beta.apk** from Assets below. Requires Android 8 or
newer. Open the APK and allow installation from the browser or file manager
when Android asks. Existing Tank Bear Beta users can install it as an update
and keep their app data. New users choose their fuel type, Imperial MPG and
litres on the Car tab, then tap Find fuel.

Location permission is optional: choose your start on the map instead. No
account or app key is needed for this friend beta. Updates are installed
manually; this is not an automatic-update channel.

## Changes

- Map opens with nearby station prices for the selected start. Expand it using
  the corner icon; map selection remains available without location permission.
- Brighter streets in dark mode and fixes for stretching/black bars when
  expanding or collapsing the map.
- Clearer journey and nearby cards, with fill estimates and expandable details
  and price history. Nearby fill estimates exclude driving costs; journey
  comparisons use routed driving costs.
- Simpler start/destination selection, clearer Car inputs and inline errors.
- Saved places have wrapping actions, save/update feedback and Undo after removal.
- Settings explains location requests, data sources and the app version.
- Search feedback shows errors once, counts down server retry waits and lets
  you cancel nearby Map lookups. Empty nearby results offer Change start.

## Testing and limitations

Android debug/beta builds, 28 unit tests, focused emulator checks and beta lint
passed during development. Full physical-phone and TalkBack review remains
open. Report problems with the app version and steps to reproduce; avoid
including private start/destination coordinates in public reports.

Prices, opening hours and savings are estimates based on available data.
Nearby distances are straight-line distances. Routing coverage and real-world
route quality are not exhaustive; Northern Ireland routing is not covered.

Fuel price data: Fuel Finder/ICS. Map data © OpenStreetMap contributors,
displayed through MapLibre using OpenFreeMap tiles. Place search uses Geoapify.
